# @mindmakr/reins

The reins core: actions, state, network and error buffers, panels and WebMCP. No dependencies, under 5 KB min+gzip.

See the [main README](https://github.com/mindmakr/reins#readme) for setup and the security model.

Flight (`@mindmakr/reins/flight` and `npx reins flight watch`) is ESM only: loaded with `import` it needs Node 18 or newer; loaded with `require` it needs Node 20.19 or 22.12 and newer (design C17).
